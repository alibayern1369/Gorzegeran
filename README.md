# 🏰 لیگ گرز گران — جام پنج پهلوان

تنظیمات لیگ اکنون از پنل مدیر قابل تغییر است: افزودن و حذف بازیکن، عکس پروفایل، تاریخ و ساعت شروع، زمان هر مسابقه، ۱ تا ۱۲ بازی در هر رویارویی با مدل‌های آماده یا دلخواه، لوگو، فاویکن و آیکون نصب PWA.
اعداد پنج بازیکن، چهار بازی، چهل مسابقه و ده شب در توضیحات زیر، ساختار پیش‌فرض داده‌های اولیه هستند. راهنمای استقرار و تست‌های مرورگر در [DEPLOYMENT.md](./DEPLOYMENT.md) آمده است.

**Garz-e Geran** — پلتفرم کامل مدیریت لیگ خصوصی پنج‌نفرهٔ کلش رویال؛ با جدول رده‌بندی خودکار،
محاسبهٔ رویارویی‌های مستقیم، جایزهٔ «دژگشای برتر»، ناحیهٔ مدیریت امن و به‌روزرسانی بلادرنگ.

## 🧱 معماری

```
Next.js 16 (App Router) + React 19 + TypeScript (strict)
Tailwind CSS 4 (کلی‌مورفیسم) + کامپوننت‌های سبک shadcn/ui (Radix)
Drizzle ORM + PostgreSQL (تولید) / PGlite (توسعه و تست)
موتورهای خالص و قابل تست:
  src/lib/engine/scoring   — قوانین امتیازدهی و اعتبارسنجی نتایج
  src/lib/engine/schedule  — تولید قطعی برنامه (روش چرخشی)
  src/lib/engine/ranking   — رتبه‌بندی با سلسله‌مراتب کامل تساوی‌شکنی
  src/lib/engine/stats     — آمار، رویارویی مستقیم، دژگشا، افتخارات
```

- **آمار هرگز تجمعی افزایش نمی‌یابد**؛ همه‌چیز از رکورد مسابقات «تکمیل‌شده» بازمحاسبه می‌شود
  (جلوگیری قطعی از شمارش دوباره).
- **اعتبارسنجی دوطرفه**: Zod در کلاینت و سرور + قیدهای CHECK در دیتابیس.
- **نشست مدیر**: توکن HMAC در کوکی HttpOnly + هش scrypt برای رمز عبور + محدودیت نرخ ورود + بررسی مبدأ.

## 🚀 راه‌اندازی سریع توسعه

```bash
# ۱) وابستگی‌ها
npm install

# ۲) متغیرهای محیطی
cp .env.example .env.local
#   — برای توسعهٔ محلی بدون PostgreSQL، DATABASE_URL را خالی بگذارید (PGlite خودکار)
#   — یا DATABASE_URL را به PostgreSQL محلی/Neon وصل کنید
#   — ADMIN_EMAIL و ADMIN_PASSWORD را برای ساخت حساب مدیر تنظیم کنید

# ۳) مهاجرت و داده‌های اولیه (۵ بازیکن، ۱۰ رویارویی، ۴۰ مسابقه، برنامهٔ ۱۰ شبته)
npm run db:migrate
npm run db:seed

# ۴) اجرای سرور توسعه
npm run dev
# → http://localhost:3000
# → ورود مدیر: http://localhost:3000/admin/login
```

### اسکریپت‌های پایگاه داده

| دستور | کار |
| --- | --- |
| `npm run db:migrate` | اجرای مهاجرت‌های Drizzle |
| `npm run db:seed` | Seed کامل (بازیکنان، تورنمنت، برنامه، حساب مدیر) — ایمن برای اجرای مجدد |
| `npm run db:reset` | حذف دیتابیس محلی PGlite (فقط توسعه) |
| `npm run admin:password` | ساخت/بازنشانی رمز مدیر از روی `ADMIN_EMAIL` / `ADMIN_PASSWORD` |

### تست‌ها

```bash
npm test          # ۶۷ تست موتور تورنمنت + یکپارچگی (PGlite در حافظه)
npm run typecheck # بررسی TypeScript
```

پوشش تست‌ها شامل هر ۲۵ سناریوی الزامی است: ساختار seed و برنامه، قوانین امتیازدهی،
رد نتایج نامعتبر، تفاضل برج، اولویت رویارویی مستقیم، مینی‌لیگ، بازمحاسبهٔ هنگام ویرایش،
جلوگیری از ثبت تکراری، کنترل دسترسی، تبدیل جلالی/تهران، مسابقات تکلیفی و رتبه‌بندی موقت.

## 🌐 استقرار در تولید (Vercel + Neon)

1. یک پایگاه دادهٔ PostgreSQL بسازید (مثلاً [Neon](https://neon.tech)) و `DATABASE_URL` را کپی کنید.
2. پروژه را به Vercel متصل کنید و متغیرهای محیطی را مطابق `.env.example` تنظیم کنید:
   - `DATABASE_URL` — اتصال Neon
   - `SESSION_SECRET` — رشتهٔ تصادفی قوی
   - `ADMIN_EMAIL` / `ADMIN_PASSWORD` — فقط برای اجرای اولیهٔ seed
   - `NEXT_PUBLIC_APP_URL` — نشانی دامنه
3. مهاجرت و seed را اجرا کنید (به‌صورت محلی علیه Neon یا در یک مرحلهٔ build جدا):

   ```bash
   DATABASE_URL="postgres://…" npm run db:migrate
   DATABASE_URL="postgres://…" ADMIN_EMAIL="…" ADMIN_PASSWORD="…" npm run db:seed
   ```

4. `vercel deploy` — همه‌چیز آماده است.
5. پس از نخستین ورود، رمز مدیر را با `npm run admin:password` تغییر دهید.

> نکته: `drizzle.config.ts` فایل‌های SQL مهاجرت را در پوشهٔ `drizzle/` تولید می‌کند؛
> برای تغییر اسکیما ابتدا `npm run db:generate` سپس `npm run db:migrate` را اجرا کنید.

## 🗓️ ساختار مسابقات

- ۵ بازیکن · ۱۰ رویارویی · ۴ مسابقه در هر رویارویی · **۴۰ مسابقه** · ۱۶ مسابقه برای هر بازیکن
- انواع مسابقه: **دک انتخابی** (custom_deck) · **درفت نوع ۱** (draft_type_1) · **درفت نوع ۲** (draft_type_2) · **اکسیر بی‌نهایت** (infinite_elixir)
- دو مرحله: مرحلهٔ یک (دک انتخابی + درفت ۱) و مرحلهٔ دو (درفت ۲ + اکسیر بی‌نهایت)
- ۱۰ شب؛ هر شب ۴ مسابقه در اسلات‌های ۰۰:۰۰ / ۰۰:۱۵ / ۰۰:۳۰ / ۰۰:۴۵ به وقت تهران؛ هر شب ۱ بازیکن استراحت
- شروع: **شنبه ۲۵ مهر ۱۴۰۵** (۲۰۲۶-۱۰-۱۷) — با فاصلهٔ ۲ شب (قابل تنظیم با `nightIntervalDays` در seed)
- برنامه با روش چرخشی (Circle Method) و به‌صورت **قطعی** تولید و در دیتابیس ذخیره می‌شود

## ⚖️ قوانین امتیازدهی و رتبه‌بندی

- برد = **۲ امتیاز** · باخت = **۰ امتیاز** · مساوی ممنوع
- نتایج مجاز: ۱–۰، ۲–۰، ۲–۱، ۳–۰ (و قرینه‌ها)؛ ۳–۱ یا ۳–۲ نامعتبر
- تفاضل برج = برج زده − برج خورده
- ترتیب رتبه‌بندی: **امتیاز → رویارویی مستقیم → تفاضل برج → برج زده → بازی تکلیفی**
- برای تساوی ۳+ نفره: مینی‌لیگ بین بازیکنان هم‌امتیاز
- تا پایان مسابقات، جدول «موقت» است و قهرمان رسمی اعلام نمی‌شود

## 🔐 امنیت

- رمز عبور با **scrypt** (Node.js crypto) هش می‌شود؛ هرگز متن ساده ذخیره نمی‌شود
- نشست در کوکی **HttpOnly / SameSite=Lax** با امضای HMAC و انقضای ۱۲ ساعته
- محدودیت نرخ ورود (۱۰ تلاش در ۱۵ دقیقه به ازای هر IP) + ثبت ورودهای ناموفق
- تمام تغییرات نتایج در `audit_logs` با مقدار قبلی/جدید ثبت می‌شود
- کاربران عمومی فقط‌خواندنی‌اند؛ هر Server Action مدیر، نشست + نقش را دوباره بررسی می‌کند
- کش Service Worker هرگز مسیرهای `/admin` و `/api` را ذخیره نمی‌کند
